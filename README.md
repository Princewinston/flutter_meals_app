# 🍽️ Flutter Meals App

A feature-rich **Meals application** built using **Flutter**, demonstrating
modern **state management with Riverpod**, smooth **animations**, and a clean,
scalable architecture.

This project focuses on building a real-world Flutter app with
structured navigation, dynamic UI updates, and user-friendly interactions.

---

## ✨ Features
- Browse meals by categories
- View detailed meal information
- Mark and manage favorite meals
- Apply filters (gluten-free, vegan, vegetarian, lactose-free)
- Drawer-based navigation and tab layout
- Clean and responsive Material UI

---

## 🎬 Animations
This project includes both **implicit and explicit animations** to enhance UX:

- **Implicit Animations**
  - Animated UI transitions using widgets like `AnimatedContainer`
  - Smooth visual feedback for state changes

- **Explicit Animations**
  - Controlled animations using `AnimatedSwitcher`
  - Custom animation timing and transitions for better user interaction

Animations are used thoughtfully to improve clarity without overwhelming the UI.

---

## 🧠 State Management (Riverpod)
State management is implemented using **Riverpod**, enabling:

- Centralized and predictable state handling
- Separation of business logic from UI
- Efficient rebuilds and better performance
- Scalable architecture for larger applications

Providers manage:
- Meals data
- Filters
- Favorites state

---

## 🏗 Architecture Overview
- **Models**: Meal and Category data models
- **Providers**: Riverpod providers for app state
- **Screens**: Categories, Meals, Meal Details, Filters, Tabs
- **Widgets**: Reusable UI components
- **Data**: Centralized dummy data source

This structure ensures clean code organization and easy maintainability.

---

## 🛠 Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Riverpod
- **UI Design**: Material UI
- **Animations**: Implicit & Explicit Animations
- **Navigation**: Tabs, Drawer, Named Routes

---

## ▶️ How to Run

1. Clone the repository
```bash
git clone https://github.com/Princewinston/flutter_meals_app.git

```

2. Navigate to the project folder
```bash
cd flutter_meals_app

```
3. Install dependencies
```bash
flutter pub get

```

4. Run the app
```bash
flutter run

```
